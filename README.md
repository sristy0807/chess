# Chess School

Learn chess step by step, then play the computer. Plays in the browser, no install: one file, `index.html`.

- **10 lessons:** the board, each piece (capture-the-pawns puzzles scored against the best possible move count), check, checkmate in one, castling / en passant / promotion, and a first game.
- **Play:** vs computer (Easy, Medium, Hard) or two players on one device. Undo, hint, flip board, move list, captured pieces.
- **Saves:** progress, stars and win counts, plus the game in progress (resume from the menu). Stored in the browser.
- **Experienced players** can skip straight to games from the first screen or in Settings.
- Full rules: castling, en passant, promotion, check, checkmate, stalemate, 50-move rule, threefold repetition, insufficient material. The move generator passes the standard perft tests.

Pushing to `main` updates the copy on https://sristy0807.github.io/sristy/ automatically.
